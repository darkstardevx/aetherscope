Packet capture, on your own interfaces.

Same category as tcpdump/Wireshark. Not a proxy like WraithFlow — this sits directly on an interface and sees everything crossing it: TCP, UDP, ICMP, ARP, anything, not just traffic you've deliberately routed through a pipeline.

Capture engine

Real libpcap, real BPF.

The exact same capture engine tcpdump/Wireshark use — via the pcap crate. BPF filter syntax (tcp port 22, udp and not port 53) comes free from libpcap, not reimplemented.

-w capture.pcap writes every frame to a real Wireshark-compatible file alongside terminal output.

Proteus — TUI

Follow TCP Stream.

The interactive browser AetherScope never had. Press s on a selected TCP packet to reconstruct the full conversation, both directions, color-coded — the actual headline feature this was built for.

j/k move · / filter · w export · ? help

Output

Three formats. One pipeline.

summary (tcpdump-style, one line), hexdump, or json — same parsed packet, three renderers. Colors sourced from the shared cybercore CYBERGRID palette, by protocol.

Verified

Round-tripped through real tshark.

pcap export/import isn't just verified against itself — Proteus's own exports were checked against real tshark reading them, and vice versa.

Install
>_ curl -fsSL https://raw.githubusercontent.com/darkstardevx/aetherscope/main/install.sh | sh

Installs both aetherscope and proteus. Needs root or CAP_NET_RAW to open a capture device — --list-interfaces works unprivileged. Note: sudo resets PATH, so a bare sudo aetherscope may say "command not found" even though it's installed — use sudo env "PATH=$PATH" aetherscope ....
